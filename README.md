# 🎓 Student Performance Prediction System

## 🚀 Overview

This project is a Machine Learning-based web application that predicts whether a student will **Pass or Fail** based on key academic factors.

It is designed to help educators identify at-risk students early and take proactive actions to improve performance.

---

## 🎯 Features

* 📊 Predict student performance (Pass / Fail)
* ⚡ Real-time predictions via web app
* 📈 Displays prediction confidence
* 🎨 Clean and interactive UI
* 🧠 Uses Machine Learning models for decision making

---

## 📥 Input Parameters

The model considers the following features:

* 📘 Hours Studied
* 📅 Attendance (%)
* 📝 Assignment Score
* 📊 Previous Marks

---

## 🤖 Machine Learning Models Used

* Logistic Regression
* Decision Tree
* Random Forest (Final Model)

---

## 📊 Key Learning

> 💡 *"Better data leads to better models."*

Initially, the model showed biased predictions. By improving dataset quality and balancing classes, prediction accuracy and reliability significantly improved.
